# React DevStack 🚀

A modern frontend development stack built with **React**, **Next.js**, and essential developer tools.  
This repo helps developers quickly set up, build, and scale React projects with best practices.

---

## ✨ Features
- ⚛️ React (Beginner–Intermediate friendly setup)
- 🔗 Next.js App Router
- 🎨 Tailwind CSS for styling
- 📡 JSON Server for mock APIs
- 🔧 Prettier + VS Code shortcuts for clean code
- 🔔 Toast notifications (React-Toastify)
- 📦 Stack counter & product fetching examples

---

```

## ⚙️ Installation & Setup
1. Clone the repo:
   ```bash
   git clone https://github.com/toufiq-tech/React-DevStack.git
   cd React-DevStack
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Start JSON Server (mock API):
   ```bash
   npm run server
   ```
